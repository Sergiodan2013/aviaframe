Agency Reporting API Reference

Pull your sales data, bookings, and revenue reports from AviaFrame. All data is scoped to your agency — you can only access your own bookings.

Base URL: https://peaceful-amazement-production-629f.up.railway.app
All endpoints require an API key. Contact your AviaFrame account manager to obtain one.

Authentication

All requests must include your API key in the Authorization header using the Bearer scheme.

# Example request with API key
curl https://peaceful-amazement-production-629f.up.railway.app/api/agency/reports/bookings \
  -H "Authorization: Bearer avf_live_YOUR_API_KEY"
Keep your API key secret. It provides read access to all your agency's booking data. If a key is compromised, contact AviaFrame support to revoke it immediately.

Key properties

  • Scope: reports:read — read-only access, no mutations possible
  • Keys can be revoked at any time by your AviaFrame account manager
  • Multiple keys can be issued (e.g. for different internal systems)

Errors

All errors return a consistent JSON structure with an error object:

{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "API key required. Use Authorization: Bearer <key>"
  }
}
401UNAUTHORIZEDMissing, invalid, or revoked API key
400INVALID_PARAMSInvalid query parameter (bad date format, unknown status)
404NOT_FOUNDThe requested order does not exist in your agency
500DB_ERRORInternal server error — contact support

Pagination

List endpoints return a pagination object alongside data:

{
  "data": [ /* ... */ ],
  "pagination": {
    "total": 143,
    "page": 1,
    "limit": 50,
    "pages": 3
  }
}

Use ?page=2&limit=50 to paginate. Maximum limit is 200.

List Bookings

GET /api/agency/reports/bookings

Returns a paginated list of bookings for your agency, sorted by creation date descending.

ParameterTypeDescription
from date optional Start date. Default: 30 days ago. Format: YYYY-MM-DD
to date optional End date. Default: today. Format: YYYY-MM-DD
status string optional Filter by status: pending, confirmed, ticketed, cancelled, refunded, failed
limit integer optional Results per page. Default: 50. Max: 200
page integer optional Page number. Default: 1 
# Fetch issued bookings for August 2026
curl "https://peaceful-amazement-production-629f.up.railway.app/api/agency/reports/bookings\
?from=2026-08-01&to=2026-08-31&status=ticketed&limit=50" \
  -H "Authorization: Bearer avf_live_YOUR_API_KEY"

Get Booking

GET /api/agency/reports/bookings/:orderId

Returns full details for a single booking, including all passengers and ticket issuance info.

ParameterTypeDescription
orderId UUID required The order_id returned in the bookings list 
# Get single booking detail
curl "https://peaceful-amazement-production-629f.up.railway.app\
/api/agency/reports/bookings/3fa85f64-5717-4562-b3fc-2c963f66afa6" \
  -H "Authorization: Bearer avf_live_YOUR_API_KEY"

Revenue

GET /api/agency/reports/revenue

Returns revenue grouped by day or month. Only confirmed and ticketed orders are counted as revenue; cancelled orders are tracked separately.

ParameterTypeDescription
fromdateoptionalStart date. Default: 30 days ago
todateoptionalEnd date. Default: today
group_bystringoptionalday or month (default: month)
# Revenue by month, last 3 months
curl "https://peaceful-amazement-production-629f.up.railway.app\
/api/agency/reports/revenue?from=2026-06-01&to=2026-08-31&group_by=month" \
  -H "Authorization: Bearer avf_live_YOUR_API_KEY"
# Response
{
  "data": [
    { "period": "2026-06", "bookings_count": 31, "revenue": 14820.00, "cancelled_count": 2, "currency": "USD" },
    { "period": "2026-07", "bookings_count": 44, "revenue": 21340.50, "cancelled_count": 3, "currency": "USD" },
    { "period": "2026-08", "bookings_count": 47, "revenue": 22150.00, "cancelled_count": 1, "currency": "USD" }
  ],
  "group_by": "month"
}

Export CSV

GET /api/agency/reports/export

Downloads all bookings as a UTF-8 CSV file (with BOM for Excel compatibility). Maximum 10,000 rows per request.

ParameterTypeDescription
fromdateoptionalStart date. Default: 30 days ago
todateoptionalEnd date. Default: today
statusstringoptionalFilter by status (same values as List Bookings)
# Download CSV for August — open directly in Excel
curl -OJ "https://peaceful-amazement-production-629f.up.railway.app\
/api/agency/reports/export?from=2026-08-01&to=2026-08-31" \
  -H "Authorization: Bearer avf_live_YOUR_API_KEY"

# Output file: aviaframe-bookings-2026-08-01-to-2026-08-31.csv

CSV columns: order_number, status, origin, destination, departure_time, airline_name, flight_number, pax_ADT, pax_CHD, pax_INF, base_price, taxes, baggage_price, total_price, currency, ticket_number, pnr, issued_at, created_at

Booking Object

All booking endpoints return booking objects with these fields:

FieldTypeDescription
order_idUUIDUnique identifier
order_numberstringHuman-readable reference, e.g. AVF12345678
statusstringCurrent order status (see Statuses)
originstring3-letter IATA departure airport code
destinationstring3-letter IATA arrival airport code
departure_timeISO 8601Scheduled departure datetime
airline_namestringCarrier name
flight_numberstringFlight number
passengersobjectPassenger counts by type: {ADT: 2, CHD: 1, INF: 0}
base_pricenumberFare before taxes and baggage
taxesnumberTaxes and fees
baggage_pricenumberBaggage surcharge
total_pricenumberTotal amount charged
currencystringISO 4217 currency code
ticket_numberstringAirline ticket number (null if not yet issued)
pnrstringGDS/airline PNR code
issued_atISO 8601Ticket issuance datetime (null if not issued)
created_atISO 8601Booking creation datetime

Order Statuses

pending Order created, awaiting payment
confirmed Payment received, booking confirmed with airline
ticketed Ticket issued — itinerary sent to passenger
cancelled Order cancelled
refunded Refund processed
failed Payment or booking failed
